# StudyOrganizer

Мобильное приложение на **Expo + React Native** для организации учёбы: расписание, календарь, заметки и т.д.

## Требования

- Node.js (рекомендуется LTS)
- npm

## Запуск (dev)

Установить зависимости:

```bash
npm install
```

Запустить Expo:

```bash
npm run start
```

Запуск без интернета (если уже всё установлено):

```bash
npm run start:offline
```

## Запуск нативной сборки (development build)

```bash
npm run ios
npm run android
```

## Полезные файлы

- `BUILD_INSTRUCTIONS.md`: общие заметки по сборке
- `XCODE_BUILD_INSTRUCTIONS.md`: сборка/настройка iOS через Xcode
